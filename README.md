# LibreChat Frontend

This repository contains only the frontend UI for LibreChat. The backend has been completely removed to provide a clean, standalone frontend application.

## 🚀 Quick Start

### Installation

```bash
# Install dependencies
npm install

# Build the frontend
npm run build

# Start development server
npm run dev
```

### Available Scripts

- `npm run build` - Build the production-ready frontend
- `npm run dev` - Start the development server
- `npm run test:client` - Run client tests
- `npm run lint` - Lint the code
- `npm run lint:fix` - Auto-fix linting issues
- `npm run format` - Format code with Prettier

## 📦 Project Structure

- `client/` - Main frontend application
- `packages/` - Shared packages (data-provider, data-schemas, client)

## ✨ Features

- 🖥️ **UI & Experience** inspired by ChatGPT with enhanced design and features
- 🎨 **Customizable Interface** that adapts to both power users and newcomers
- 🌎 **Multilingual UI** with support for 30+ languages
- 📥 **Import & Export Conversations** in multiple formats
- 🔍 **Search & Discovery** across all messages and conversations
- 💾 **Presets & Context Management** for advanced customization

## 🛠️ Technical Stack

- React 18
- Vite
- TypeScript
- TailwindCSS
- Radix UI components
- React Query (TanStack)
